Your Calling List

Bulk Upload calling lists to your panel

Power upload allows you to load and distribute a huge list of data you might have to your self / agents. It allows you to load up to 100,000 records at once for distribution.

Please ensure the file you are uploading is a CSV,XLS,XLSX file.

Upload File

Instructions to Upload Numbers via Power Import

Question: What is a CSV file and where can I edit it?

Answer: A CSV file is a Comma Separated Value file that you can create in Microsoft Excel, LibreOffice, OpenOffice, or Apple Numbers software. It is like an XLS file without the unnecessary codes that hinder data upload. Check out this video to know What is a CSV?

Question: What is Power Import?

Answer: Power Import is a functionality that we created in Calley so that the Calley Admin does not need to lose too much time in uploading numbers in the Calley Web Panel. The Standard Import is limited to 2000 numbers upload at once, which becomes frustrating for the admin to load and distribute data. Using Power Import, you can upload as many as 100,000 numbers to the system at once.

Question: Is there a structure to follow when making CSV for Power Import?

Answer: That is the beauty of Power Import; it works without a fixed structure. All you need is to select the CSV file that you want to upload. Once uploaded in the Calley Web Panel, you can map fields in your CSV file to Calley Web Panel's required fields and click on Import Data.

Question: Do I get a Single List of 100,000 numbers?

Answer: No, Power Import will make the first list instantly for you to make calls. It schedules the rest for distribution in 15 mins. You get an intimation of successful distribution on your email.

Question: Do you validate data in Power Import?

Answer: Yes, we do. In case we find duplicate numbers or invalid records in your CSV file, we send them to you via email on your registered email id. Valid data gets imported successfully.

Question: My file does not upload successfully?

Answer: This may happen because your fields have special characters. We recommend that you remove all the special characters from your CSV file before Import. Commas (,) and Apostrophe (') are a BIG NO, while we recommend that you refrain from using special characters as much as possible for file import.

If you still have questions for us to answer prior to uploading your file or if you are facing challenges in uploading file you can initiate a live chat with us or email us on support@getcalley.com
